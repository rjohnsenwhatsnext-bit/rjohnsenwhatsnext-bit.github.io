# Burrow Count artwork

Original vector and CSS artwork authored for this game. No external fonts or image requests.
- icon.svg: 512 square icon master, woodland critter and clue stone.
- feature.svg: 1024 x 500 promotional illustration, not a gameplay screenshot.
- ../style.css: scalable critters, earned colour variants, Keeper hat, menu habitat and board presentation.

Palette: forest #243e34, parchment #eef0da, clay #b66538, leaf #aabc83. Rounded shapes, quiet paper grain, readable labelled regions. Motion is limited to earned-result blooms and disabled with reduced motion.

Store PNG exports and actual gameplay screenshots remain for the packaging and verification stages. No visual or device acceptance is claimed.
