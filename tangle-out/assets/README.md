# Tangle Out artwork

Original vector artwork drawn in code for this game. No external fonts, imagery or copied game assets.

- `icon.svg`: 1024 square vector master, menu illustration and favicon. Game metadata points here.
- `feature.svg`: 1024 by 500 matching promotional artwork. This is illustrative artwork, not a gameplay screenshot.
- The play board is drawn directly as SVG in `main.mjs`, using rounded coloured lines and directional arrowheads. Striped coral identifies a blocker; a thicker outline identifies a rewarded hint.

Raster native/store exports and actual gameplay screenshots are outstanding. No browser visual acceptance or native packaging is claimed in this coding stage. Preserve the ivory, teal, clay and violet direction when exporting.
